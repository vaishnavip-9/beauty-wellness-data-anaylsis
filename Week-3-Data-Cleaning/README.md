# Week 3 – Data Cleaning and Preprocessing

## Internship
YuvaIntern – Data Science with Python Analyst Internship

## Project
Analysis of Customer Purchase Trends in the Beauty and Wellness Industry

## Objective
To develop a data cleaning and preprocessing pipeline using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Tasks Completed
1. Dataset loading and inspection
2. Missing value handling
3. Duplicate removal
4. Invalid value checking
5. Outlier detection
6. Data standardization
7. SalesAmount calculation
8. Saving cleaned data

## Dataset
UCI Online Retail Dataset (first 5,000 rows used).

Note: This is a general retail dataset, not a beauty and wellness-specific dataset.

## Results
- Final dataset: 4,839 rows × 9 columns
- Duplicate records: 0
- Missing CustomerID: 1,193
- Average SalesAmount: 21.443213

## Conclusion
The dataset was cleaned and preprocessed successfully using Python libraries.
